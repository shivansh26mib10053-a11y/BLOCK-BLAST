# Block Blast Python Game

An elegant, object-oriented Python implementation of the modern **Block Blast** puzzle game using standard `pygame`.

---

## 🎮 Features
- **Responsive Controls:** Mouse drag-and-drop with automatic grid snapping.
- **Visual Feedback:** Scaled pieces, dark dark-mode palette, clean UI.
- **Line Clearing & Combos:** Dynamic row/column detection with bonus exponential combo scoring.
- **Game Over Detection:** Auto-checks if remaining blocks have no valid placement positions left.
